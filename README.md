## The entry

> ★☆☆☆☆ Monday charged me for the weekend, delivered nothing, and scheduled a 9 a.m. meeting to ask why I looked tired.

One line, 117 characters — a one-star review of Monday with a concrete
detail (the 9 a.m. meeting) and a twist: the day that drained you then
holds a meeting to ask why you look drained.

## How it works

`main.py` (Python standard library only) writes the review line to
`$ENTRY_OUT`, supporting both a file path and a directory (in which case
it writes `entry.txt` inside it).

```sh
ENTRY_OUT=/output/entry.txt python3 main.py
```
